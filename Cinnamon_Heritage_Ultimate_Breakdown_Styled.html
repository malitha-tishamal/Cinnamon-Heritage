3. High-Quality Media Hosting: Cloudinary Architecture

To ensure high performance and eliminate server disk consumption, all image uploads across the platform (product images, section full-width backgrounds, step illustrations, and user avatars) are offloaded to Cloudinary's global media network.

Direct-to-Cloud Upload Streaming

Admin uploads do not pass through intermediate web servers. Uploads stream directly via an unsigned upload preset to Cloudinary using XMLHttpRequest, which provides continuous byte-level progress updates (0% to 100%).

Edge Optimization & Security

Images are automatically delivered in modern WebP format with responsive dimensions, saving over 70% bandwidth while maintaining high resolution on Retina and 4K displays.

Customer Live Stepper (Daraz/Amazon Style)

When an order is placed, customer cart automatically clears and redirects to the "My Orders" tab inside the drawer. The 5-stage stepper (Pending ➔ In Progress ➔ Packed ➔ Shipped ➔ Completed) pulses in real time as the admin updates the status.

Admin Account Security Gate

Self-registered admins cannot access the portal immediately. New accounts receive is_approved: false and status: 'pending'. An existing Super Admin must approve them from the Admin Accounts panel before login is granted.

9. Security, Integrity & Performance Guarantees

ACID Inventory Integrity

All orders run inside Firestore transactions to prevent race conditions, double-orders, or negative inventory states.

Sub-Second Preloader

1-second maximum hard limit with session caching guarantees snappy user experience on high-latency mobile networks.

Zero Server Bloat

All media assets are securely hosted on Cloudinary CDN, ensuring zero server disk consumption and optimal bandwidth usage.
